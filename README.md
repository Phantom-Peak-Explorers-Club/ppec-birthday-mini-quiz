# PPEC Quiz

A static birthday quiz with four games: Littlefield’s Letters, Say What You See?, Missing Vowels, and What Trail? The portal and game screen are styled as a compact game console featuring Jonabot Jr.

Each game offers a ten-question Quiz Round or Unlimited. Unlimited ends at the first incorrect or revealed answer, or when the question pool runs out. A cleared pool displays “More questions coming soon.” Anagrams and Missing Vowels start with a 3–2–1–Go countdown, then give 30 seconds per clue. Say What You See? and What Trail? are untimed. In the picture game, players choose squares from a 6×4 cover and earn `24 - panels opened` points for a correct answer. It accepts punctuation/spacing variants, a few natural short forms, and minor typing errors. The letter games require the intended answer.

Anagram answers animate the scrambled letters into the solved order, and Missing Vowels drops the restored vowels into place, including after a wrong guess. Results show the game, mode, score, questions completed, and elapsed time. Players can share a square 1080 × 1080 PNG card or copy a text result. Each game has its own colour on the portal, console, result preview, and exported card: gold, teal, violet, or coral.

Question data is in `docs/app.js`: 87 anagrams and 103 Missing Vowels answers (102 distinct consonant clues). Anagrams have a difficulty `tier` (1–4); Quiz Round draws 2/3/3/2 questions by tier. Missing Vowels terms are stored as `{answer:'PHANTOM PEAK'}`; the displayed clue removes A, E, I, O, and U. Terms with identical consonants form one question, show only the primary answer length, and accept any matching answer in the full bank (including JONACOIN and JONACON for JNCN). Any question can include `contributor:'Name'`, shown as a credit on the question screen. The [letter clue list](CLUE-BANK.md) records the selected pool and source notes; regenerate it with `node scripts/build_clue_bank.cjs` after editing questions.

What Trail? draws from a snapshot of all 187 public Trail Notes records in `source/trails.json`. Each clue has three answer choices total, with the order shuffled each time. The [complete question sheet](WHAT-TRAIL-QUESTIONS.md) shows all clues, options, and correct answers for review. Regenerate it and `docs/what-trail.js` with `node scripts/build_what_trail.cjs` after refreshing the source snapshot.

Run `node --test tests/game.test.cjs` to check the game rules. Serve `docs/` over HTTPS or localhost to test web app installation and offline caching; simply opening `docs/index.html` also works for the quiz itself. The manifest, service worker, and icons live in `docs/`. Browser Back and Forward move between portal, game, and results screens. No account, build step, or backend is required.

Source references: `Backup Quiz PPT.pptx`, the XP Studio quiz export, the images in `Catchphrase Round`, [PPEC Trail Notes](https://ppec.club/trail-notes/), and the linked official map/guide in `CLUE-BANK.md`. Original Desktop source files were left untouched.
